# File Organizer

## Overview

The **File Organizer** is a Python-based business automation utility designed to organize files into structured folders based on their file types.

The application automates a repetitive file-management task that would otherwise require users to manually sort documents, images, spreadsheets, PDFs, and other files.

This project demonstrates how Python can be used to automate routine administrative tasks, improve file organization, and reduce manual effort.

---

## 🎯 Project Goal

Build a reliable file-management automation tool that can process a directory and organize its files into logical categories.

The goal is to demonstrate practical automation using Python while following a modular software-development approach.
